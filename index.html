  1. Create a free Supabase project.
  2. Run the SQL in supabase/schema.sql.
  3. Copy the Project URL and anon key into config.js.
  4. Create admin users in Supabase Authentication and grant admin access using the SQL instructions.
  5. Publish the folder on GitHub Pages or Netlify.
